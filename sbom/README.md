# Software Bill of Materials (SBOM)

`starter-theme.cdx.json` is a [CycloneDX](https://cyclonedx.org/) 1.5 SBOM for this
theme. It has **no third-party runtime dependencies** (the empty `components` array
is intentional) — it consists of Blade views and static assets rendered by the
Nioteq CMS host. Update the `version` when releasing.
